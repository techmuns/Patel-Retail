# Patel Retail Dashboard

Scaffolding for a Patel Retail dashboard, built for an investment firm doing
diligence.

**Start here:** [`PATEL-HANDOFF.md`](./PATEL-HANDOFF.md) — what's in this
repo, where it came from, and what's still missing before real feature work
can start.

## Status

Scaffold only. Design system, export tooling, and hosting shell are copied
in and working; there is no Patel Retail data, store map, or store schema
yet — see the handoff doc's "Missing" section.
